# matthias-matthies/tap

Homebrew tap for [lights-off](https://github.com/matthias-matthies/lights-off).

```sh
brew install --cask matthias-matthies/tap/lights-off
```

This also installs its dependencies: [`sbx`](https://github.com/docker/sbx-releases) from `docker/tap`, and `gh`.

`brew uninstall --zap lights-off` also deletes lights-off's config, secrets, cache and run logs.
